BREACH.MMO v1.9.0 — 2026-06-03

Multiplayer Live Ops

v1.9.0 gives competitive players a reason to return every week. Three live-ops systems ship simultaneously: time-limited faction wars, rotating exploit challenges, and a real-time CVE feed that turns fresh vulnerabilities into in-game missions within 48 hours of disclosure.

Faction War Season Events — APT-themed competitive events run on two-week seasons. Red and Blue team factions battle for season leaderboard position, with 2× season points during active events. Top-3 finishers in each faction earn a cosmetic title badge. The first event — Cozy Bear Q3 — opens July 6. The season leaderboard is live now via the LADDER button in the nav.

Weekly Rotating Exploit Challenges — three new challenges drop every Monday UTC: one for Red team, one for Blue team, and one cross-functional Education challenge. Each carries 3× XP for the week it's active. The weekly panel is accessible from the main nav and shows a live countdown to the next reset.

Live CVE Challenge Feed — the CVE ingestion pipeline that's been running in the background since v1.6.0 now surfaces to players. The new CVE Intel Board panel displays real-time vulnerabilities from NVD and GitHub Advisory, ranked by CVSS score. When a CVE is flagged as gameplay-viable, it becomes a 48-hour live challenge. Breaking CVEs also trigger an in-game notification. Security news is now the patch schedule.
