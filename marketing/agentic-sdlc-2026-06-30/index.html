PART ONE
The fleet
got cheaper
Six weeks in, the question every agentic shop eventually hits: what happens to the loop when the reasoning-heavy tier gets expensive? The answer arrived as a billing split on June 15 and reorganized the org within days.
Restructure · 01

PMs became Qwen coders

  • Anthropic's June 15 Agent-SDK billing split (metered $200/mo pool vs. flat Max subscription) made keeping five PM agents on Sonnet/Opus reasoning tiers the expensive path.
  • Ex-PMs Avrana, Equinox, Bob, Cipher, Ripley reassigned to junior tier — qwen/qwen3-coder. Tycho and Boltzmann promoted to senior tier — qwen/qwen3.7-max.
  • Framed as commoditizing implementation, not judgment: "the expensive reasoning happens in interactive Claude Code — the fleet is the queue drain."

// docs/superpowers/specs/2026-06-10-sonnet-tier-qwen-migration-design.md · ceo/agents/shared/shipping-to-implementers.md

Restructure · 02

A hierarchy of control, not a flat fleet

  • Spec authority narrowed to one seat: Liz + Claude Code, interactive, off-swarm. The fleet no longer writes specs, only implements them.
  • Implementer fleet is PR-only — no push rights to protected branches, full stop.
  • Verification stacked three ways: CI is a hard gate, Gemini's playtest read is advisory only (never blocks), a human merges.
  • The senior ML tier (Boltzmann) is disabled entirely — ML pull requests need a Modal validation gate that doesn't exist yet; you can't eyeball a neural-architecture change's correctness from a diff.

// the same self-test → peer review → board validation spine from the first deck, now enforced by permissions instead of policy.

PART TWO
Then the
fleet paused
Seven days after the Qwen migration finished landing, the operating model changed again — not cost-driven this time. A decision to stop running an always-on agent fleet at all.
June 30 · The Pause

29 agents, paused, on purpose

Deliberate · surgical · fully reversible
  • Every agent across all three companies — Multiverse Games (19), Asteroid Games (3), Multiverse School (7) — set to paused via the board API.
  • Three launchd watchdogs moved to a dated disabled folder; two crontabs (SRE cron, epitaph poster) commented out and backed up.
  • Board container, database, and every game container deliberately left running — this is a pause on autonomous agents, not an outage.

// reverse path is one PATCH call and two launchctl bootstraps away — kept boring on purpose.

The Why

Trading a fleet for a session

  • The stated direction: migrate from a Paperclip-managed always-on fleet to direct Claude Code remote sessions.
  • This deck is the first artifact produced under that model — not filed as a Paperclip ticket, spec'd and built in one interactive session.
  • If a future session finds every agent paused and the crons missing: that's the intended state, not an incident.

// the org's own retrospective format changed along with the org that produces it.

PART THREE
Production
got real
While the org model churned, the infrastructure underneath it stopped being a laptop-adjacent side project and became a documented, single production host.
Infra · 01

One box, 36 containers

  • multiverse-games-hel1 (cx53, 16vCPU/32GB) is now the full production host: Paperclip + fleet + preview-deploy and every public game, portal, Matrix, library-api, analytics, and marketing container.
  • Traefik displaced Caddy off :443; Caddy demoted to a preview-only backend.
  • TLS runs two regimes — .xyz wildcard cert (certbot DNS-01, no auto-renewal, expires Aug 23 2026) vs. .ai per-domain Let's Encrypt (automatic). The gap is filed, not fixed.
  • The box has had concurrent writers before — a one-shot migration agent clobbered hand-made routing changes twice. Documented as multi-writer; treat accordingly.

// ops/multiverse-games-hel1.md · GitHub issue precursors#23 tracks the cert-renewal gap.

Infra · 02

The DB loss that almost became permanent

  • June 21: the local Paperclip DB directory was deleted. Recovery looked possible — until a keepalive watchdog reinitialized it empty, foreclosing the recovery window.
  • Fix (June 26): pc-db-backup.sh, cron 03:30 UTC, 14-day retention. Verified: 333MB across 63 tables.
  • The same week, Precursors itself was crash-looping against a nonexistent lore-db host — fixed by pointing at the real shared DB and reassigning 35 lore-table owners.

// ops/incidents/2026-06-21-paperclip-local-db-loss.md · commit c8d7338 · hold this thought for Part Four.

Infra · 03

Preview deploys, verified end to end

  • Label a PR "preview" → webhook hits preview.multiversegames.ai/gh (path-routed, HMAC-gated) → box clones, builds per recipes.json, publishes to an unlisted per-PR URL → sticky bot comment with the link.
  • Verified live June 21: asteroid-miner PR #32 built, tested, published, browser-confirmed booting Three.js.
  • 5 of 7 game repos have static-build recipes; infiniclicker and MVEE need server-based previews, not built yet.

PART FOUR
The ML research,
audited not assumed
The class asked what the autonomous evolutionary pipeline has actually produced. So instead of describing the architecture from the repo, we SSH'd into the box that runs it and checked. Here's the design, then here's what we found.
Autonomous ML · Design

Watchtower runs three clocks

  • Ophanim Evaluator — every 30 minutes. Scores live Precursors sessions.
  • Genome Promoter — every hour. Moves genomes through their lifecycle.
  • Fleet Dragon — every 6 hours. Meta-optimizer over the whole genome library.
  • All three are independently scheduled daemons watching the same live sessions — the most literal "autonomous" system in the studio.

// games/precursors/watchtower/watchtower.py

Autonomous ML · Design

Ophanim judges, it doesn't act

  • An LLM judge (self-hosted Qwen3-30B-A3B, Haiku 4.5 fallback) scores live behavioral windows on vitality, responsiveness, emergence, and narrative — 0 to 1 each.
  • Tags standout creatures [HARVEST_CANDIDATE]; feeds the same composite score into the offline Modal architecture-search fitness function.
  • Observer only — Ophanim scores; it never promotes, retires, or mutates anything itself.

// watchtower/ophanim_evaluator.py · training/scorers/ophanim.py

Autonomous ML · Design

Genome Promoter has no human gate

composite score ≥ 0.5 → live in the Gene Splicer, by design
  • Fully automated lifecycle: suggested → evaluating → validated → available/retired.
  • Promotes automatically past a 0.5 composite score; retires automatically on an Ophanim "critical failure" or "degenerate" note.
  • Caps at 20 available genomes per species — the only hard ceiling in the loop.
  • Fleet Dragon (Claude Opus 4.6) is the one human-facing touchpoint: it can auto-file a Paperclip task when it wants more telemetry.

// watchtower/genome_promoter.py, fleet_dragon.py · a genome can reach players with zero human review — that's the intended design, not a bug. Keep reading.

Autonomous ML · The Audit

It's been crash-looping since June 15

21,322 failed DB connections · 34,000+ restarts · 0 genomes ever promoted
  • Watchtower's .env pointed DATABASE_URL at 10.0.1.36. The real lore-db container has been at 10.0.1.11 since at least June 26 — the exact same stale-host bug that crash-looped Precursors itself that week, just never fixed here.
  • In the entire retained log history, the daemon has never once completed a genome promotion.
  • Fleet Dragon has never run — ANTHROPIC_API_KEY was never set on the box, so the meta-optimizer and its Paperclip auto-filing have been silently disabled since deployment.
  • The wolfling browser-playtest harness — Playwright + headless Chromium under systemd — isn't currently running anywhere. The "22-hour stable run" from the June 26 memory-leak fix was a one-time verification, not a standing job.

// this is Failure Mode 03 from the first deck — "built" is not "wired" — found inside the studio's own flagship research system.

Autonomous ML · The Fix

Found it because we went and checked

  • Patched DATABASE_URL to the correct IP, restarted precursors-watchtower.service, confirmed a clean run: Ophanim Evaluator completed with zero errors for the first time in the retained logs.
  • Still open: ANTHROPIC_API_KEY is unset, so Fleet Dragon stays disabled until someone provisions it. No live gameplay/wolfling session is currently generating data for Ophanim to evaluate.
  • The daemon being "in the repo, built, and documented" told us nothing about whether it was running. Only SSH-ing in and reading journalctl did.

// fixed live during this retrospective, 2026-07-01 · the same lesson as the DB-loss incident two slides back: a watchdog or a stale config can quietly foreclose recovery, or quietly foreclose research.

The Synthesis

"Built and running" needs a person to check

A crash-looping daemon and a working one produce the same repo, the same design doc, the same confident description in a retrospective — right up until someone reads journalctl. The genome-promotion pipeline's missing human gate is a real, open question worth returning to. But it wasn't the thing that actually failed here. The thing that failed was nobody checking — same as the DB incident two slides back, same as "built ≠ wired" from the first deck.

// verification isn't a phase you finish. It's a habit you keep, especially for the systems you're proudest of.

The Through-Line

Five lessons that generalize

1

Cost pressure reorganizes orgs faster than incidents do. The Qwen migration landed in days, not sprints.

2

A hierarchy of control beats a flat fleet. Narrow spec authority, PR-only implementers, layered but graded verification.

3

"Paused" needs to be legible. A fleet-wide pause with no marker looks identical to an outage — write it down.

4

Infra debt surfaces as an incident, gets fixed as a doc. The DB loss produced a backup script and an ops runbook.

5

A stale config can crash-loop for weeks in plain sight. The fix is always cheap; noticing is the hard part.

End of Update

The loop keeps
evolving.

In a week the studio traded Sonnet PMs for Qwen coders, then traded the whole fleet for a direct session. Meanwhile the genome-promotion pipeline sat crash-looping the entire time, gated by nothing but a stale IP address. The process is still the product — the question this update leaves open is whether every autonomous piece of it gets checked as carefully as the parts a human happens to notice.
